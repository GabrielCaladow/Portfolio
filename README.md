# Portfólio · Gabriel Calado

Portfólio pessoal de Gabriel Calado, estudante de Ciência da Computação na CESAR School, em Recife.

Feito só com HTML, CSS e JavaScript, sem framework e sem etapa de build: o navegador lê os arquivos como estão.

## Como rodar

O site precisa de um servidor local, porque usa módulos JavaScript (`type="module"`). Abrir o `index.html` com duplo clique não funciona.

1. Abra a pasta no VS Code.
2. Instale a extensão **Live Server**.
3. Clique em **Go Live**, no canto inferior direito.

## Estrutura

```
index.html            página principal
assets/css/           tokens (cores e medidas), base, layout e componentes
assets/js/            main.js (entrada) e um módulo por comportamento
assets/icons/         sprite.svg com todos os ícones
assets/fonts/         fonte Geist e a licença dela
```
